Política de privacidad

Esta política explica de forma general cómo Sistema Maestro IA puede tratar datos personales relacionados con el uso de la plataforma.

Datos que pueden tratarse

Según el uso de la plataforma, pueden tratarse datos como correo electrónico, información introducida en formularios, datos de suscripción, datos técnicos de navegación y datos necesarios para gestionar el acceso al servicio.

Finalidad

Los datos pueden utilizarse para permitir el funcionamiento de la plataforma, gestionar el acceso al Plan Pro, procesar pagos, mejorar el servicio, atender consultas y mantener la seguridad del sistema.

Pagos

Los pagos se gestionan mediante Stripe. Sistema Maestro IA no almacena directamente los datos completos de tarjeta bancaria.

Servicios de terceros

La plataforma puede utilizar servicios externos necesarios para alojamiento, analítica, pagos, automatización o funcionamiento técnico.

Derechos del usuario

El usuario puede solicitar información, rectificación o eliminación de sus datos escribiendo al canal de soporte del proyecto.

Uso de IA

Los textos o datos introducidos por el usuario pueden ser utilizados para generar respuestas mediante sistemas de inteligencia artificial. El usuario debe evitar introducir información sensible innecesaria.

Contacto

Para consultas sobre privacidad, utiliza el canal de soporte de Sistema Maestro IA.
