Política de privacidad

Esta política explica cómo Sistema Maestro IA puede tratar datos personales relacionados con el uso de la plataforma.

Datos que pueden tratarse

Podemos tratar datos como correo electrónico, información introducida en formularios, datos técnicos de navegación, datos de uso de la plataforma y datos necesarios para gestionar suscripciones o pagos.

Finalidad

Los datos pueden utilizarse para permitir el funcionamiento del servicio, gestionar el acceso al Plan Pro, procesar pagos, mejorar la plataforma, atender consultas y mantener la seguridad del sistema.

Pagos

Los pagos se gestionan mediante Stripe. Sistema Maestro IA no almacena directamente los datos completos de tarjeta bancaria.

Servicios de terceros

La plataforma puede utilizar servicios externos necesarios para alojamiento, pagos, analítica, automatización o funcionamiento técnico.

Uso de inteligencia artificial

Los textos o datos introducidos por el usuario pueden utilizarse para generar respuestas mediante sistemas de inteligencia artificial. Se recomienda no introducir información sensible innecesaria.

Derechos del usuario

El usuario puede solicitar información, rectificación o eliminación de sus datos escribiendo a: soporte@sistemamaestroia.com

Contacto

Para consultas sobre privacidad: soporte@sistemamaestroia.com
