Sistema Maestro IA

Política de privacidad

Esta política explica cómo tratamos la información relacionada con la app Sistema Maestro IA.

App: Sistema Maestro IA Package: com.sistemamaestroia.app Última actualización: 08/06/2026 Contacto de privacidad: privacy@sistemamaestroia.com

1. Datos que puede recoger la app

Sistema Maestro IA puede tratar los siguientes datos, según el uso que hagas del servicio:

  • Datos introducidos voluntariamente por el usuario en formularios, prompts, mensajes o campos de la app.
  • Email u otros datos de contacto si el usuario los proporciona para soporte, acceso, comunicación o gestión del servicio.
  • Datos técnicos básicos, como tipo de dispositivo, navegador, sistema operativo, idioma, registros técnicos o información necesaria para seguridad y funcionamiento.
  • Datos de uso o analítica si se activan herramientas de medición para entender errores, rendimiento y uso general del servicio.
  • Datos de pago si el usuario contrata un plan o servicio mediante Stripe u otro proveedor externo de pagos. En ese caso, los datos de pago se gestionan principalmente por el proveedor de pagos.

2. Para qué se usan los datos

  • Permitir el funcionamiento de la app y sus asistentes.
  • Generar respuestas, textos, estructuras, ideas, automatizaciones o resultados solicitados por el usuario.
  • Mejorar el servicio, corregir errores y entender qué funciones son más útiles.
  • Prestar soporte y responder consultas.
  • Realizar analítica básica de uso, rendimiento y estabilidad si aplica.
  • Gestionar pagos, suscripciones, facturación o acceso a funciones de pago si aplica.

3. Terceros y proveedores

Para operar el servicio podemos apoyarnos en proveedores externos, por ejemplo:

  • Servicios de hosting, infraestructura, almacenamiento o despliegue web/app.
  • Google y Google Play para distribución, revisión, métricas, funcionamiento del sistema Android o gestión de la ficha de la app.
  • Herramientas de analítica, medición o diagnóstico técnico si se usan.
  • Stripe u otros proveedores de pago si se activan compras, suscripciones o pagos externos.

Estos proveedores pueden tratar datos según sus propias políticas y solo en la medida necesaria para prestar el servicio.

4. No venta de datos personales

No vendemos datos personales de los usuarios.

5. Seguridad

Aplicamos medidas razonables para proteger la información frente a accesos no autorizados, pérdida, uso indebido o alteración. Aun así, ningún sistema conectado a internet puede garantizar seguridad absoluta.

6. Conservación de datos

Conservamos los datos solo durante el tiempo necesario para prestar el servicio, cumplir obligaciones legales, resolver incidencias, prevenir abuso o mantener registros operativos razonables. Cuando los datos dejan de ser necesarios, se eliminan o se anonimizan cuando sea posible.

7. Derechos del usuario

El usuario puede solicitar acceso, rectificación, eliminación, oposición o limitación del tratamiento de sus datos escribiendo a privacy@sistemamaestroia.com. Para poder atender la solicitud, podemos pedir información mínima que permita verificarla.

8. Eliminación de datos

Para solicitar la eliminación de datos relacionados con Sistema Maestro IA, consulta la página específica:

https://sistemamaestroia.com/data-deletion.html

9. Cambios en esta política

Podemos actualizar esta política para reflejar cambios legales, técnicos o funcionales. La fecha de última actualización indicará la versión vigente.
