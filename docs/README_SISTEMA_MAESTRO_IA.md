# Sistema Maestro IA

## Qué es

Sistema Maestro IA es una plataforma de asistentes de inteligencia artificial especializados para crear, vender, automatizar y monetizar proyectos digitales.

No es un chat genérico.

Es un hub de asistentes preparados para tareas concretas. Cada asistente cumple una función específica dentro del sistema.

La idea principal:

Elige un asistente, responde un formulario simple y recibe una salida lista para usar.

## Arquitectura general

El proyecto tiene frontend y backend.

Estructura principal:

SISTEMAMAESTROIA
- sistemamaestroia-frontend
- sistemamaestroia-backend
- REGLAS DEL SISTEMA
- estructura_sistemamaestroia_actual.txt
- README_SISTEMA_MAESTRO_IA.md
- PLAY_STORE_SISTEMA_MAESTRO_IA.md

El frontend muestra la landing, demo, asistentes, checkout y experiencia de usuario.

El backend gestiona la lógica, límites, asistentes, usuarios, pagos o integraciones según la implementación actual.

## Diferencia frente a ChatGPT

ChatGPT es una herramienta general.

Sistema Maestro IA es un sistema organizado por asistentes especializados.

Diferencia clave:

- ChatGPT depende de que el usuario sepa escribir buenos prompts.
- Sistema Maestro IA guía al usuario con asistentes preparados.
- ChatGPT responde de forma abierta.
- Sistema Maestro IA produce salidas orientadas a tareas concretas.

Frase clave:

No vendemos otra IA. Vendemos estructura para usar IA mejor.

↓
